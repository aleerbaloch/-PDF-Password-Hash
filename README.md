🔐 Week 3 Cybersecurity | PDF Password Hash Extraction & Recovery
I'm excited to share that I've successfully completed another hands-on cybersecurity lab as part of my Network Walks learning journey!
In this practical exercise, I worked with three password-protected PDF files and explored how password hashes can be extracted and audited using Kali Linux.

🛠️ Tools & Technologies Used:
Kali Linux
John the Ripper
pdf2john
RockYou Wordlist

💻 Tasks Performed:
Extracted password hashes from three password-protected PDF files using pdf2john.
Identified and verified PDF hash formats.
Used John the Ripper to perform dictionary-based password auditing.
Successfully recovered a PDF password using the RockYou wordlist.
Verified the results using John the Ripper's --show command.

📚 Key Learning Outcomes:
Understanding password hash extraction.
Learning how dictionary-based password attacks work.
Gaining practical experience with John the Ripper.
Understanding password recovery and auditing techniques.
Recognizing the importance of strong and unique passwords.
This hands-on lab helped me improve my practical understanding of password security and ethical hacking techniques.
